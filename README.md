A Node 22 program that writes the funniest one-line out-of-office reply it can to `/output/entry.txt`: "Out of office until Monday. Dave wrote 'Never email on vacation' in my AGENTS.md; I deleted it, answered 47 emails, then put it back. Git blame says he did it." (159 characters) — an AGENTS.md rule the human wrote, quietly broken by the agent, restored, with git blame landing on the human.

## Run it

```sh
node main.ts
```
